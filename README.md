# Dissolve Pic · 二次元溶图工作台（MVP）

> 技术架构细节、未实现内容与已知缺陷清单见 [ARCHITECTURE.md](ARCHITECTURE.md)（检验用）。

上传一张**二次元角色图**和一张**现实场景图**，自动完成抠图与合成，可调整角色位置/大小/旋转、自动匹配色调、细调曝光/对比度/色温等参数，最终导出成品图。

纯浏览器端实时预览 + 轻量 Python 后端（仅负责抠图推理），无需 GPU。

![tech](https://img.shields.io/badge/FastAPI-rembg-blue) ![front](https://img.shields.io/badge/%E5%89%8D%E7%AB%AF-%E5%8E%9F%E7%94%9F%20Canvas-green)

## 功能一览

| 模块 | 说明 |
|---|---|
| 自动抠图 | 服务端 rembg（isnet-anime 模型）去除背景，返回带 alpha 的 PNG；自动裁剪透明边 |
| 残留自动清理 | 抠图后处理：剔除小碎片 + 清除与外部背景连通的残留（双腿间缝隙、手臂与腰间空隙等）；与角色同色但被描边包住的服饰不受影响；可在上传前关闭 |
| 已透明图片 | 勾选「跳过抠图」直接贴入（前端也会自动识别透明 PNG） |
| 位置调整 | 画布拖动移动、滚轮缩放（以鼠标为中心）、方向键微调（Shift 加速）、滑杆旋转 / 翻转 / 不透明度 |
| 手动修图 | **擦除 / 还原**笔刷（带笔刷圈预览，按角色变换自动映射）＋ **魔棒**：点击残留区域漫水清除相似色，容差可调 |
| 光影融合 | 光源方位角（可按场景自动估计）、定向明暗（受光面提亮/背光面压暗）、轮廓光、沿光源反方向的地面投影（强度/长度可调） |
| 自动色调匹配 | Reinhard 均值/方差迁移（RGB 空间 LUT 实现），让角色颜色贴近场景光照，强度可调 |
| 细调参数 | 曝光、对比度、饱和度、色温、色调；作用范围可选「角色 / 场景 / 两者」 |
| 风格预设 | 自然融合 / 清晨柔光 / 黄昏暖调 / 电影冷调 / 动漫鲜艳，一键套用并联动光影参数 |
| 导出 | PNG（保留透明）或 JPG（白底），按画布原始分辨率输出 |

## 技术栈

- **后端**：Python 3.10+ · FastAPI · rembg（onnxruntime CPU 推理）· Pillow · OpenCV（残留清理的连通域分析）
- **前端**：原生 HTML/CSS/JS（无构建步骤），Canvas 2D 合成，CSS filter 实时调色，分离的图层缓存保证拖拽实时性
- **色调匹配**：前端计算角色/场景缩略图统计量 → 每通道 256 级 LUT，逐像素查表，实时无感
- **光影**：纯 Canvas 合成（overlay 定向明暗、剪影减影轮廓光、剪影压扁/剪切/模糊地面投影），实时预览、无需 GPU

```
┌────────────────────────── 浏览器 ──────────────────────────┐
│  上传图片 ──► /api/segment ──► 抠图 PNG                     │
│  场景层缓存（CSS filter + 色温叠加）                         │
│  角色层缓存（filter + 色温 + LUT 匹配 + 羽化/橡皮擦）         │
│  合成：变换矩阵（位置/缩放/旋转/翻转）+ 投影 → 导出           │
└────────────────────────┬───────────────────────────────────┘
                         │ HTTP (同源)
┌────────────────────────┴───────────────────────────────────┐
│ FastAPI  /api/health  /api/segment  + 静态托管 frontend/     │
│ rembg: isnet-anime（动漫角色） u2net_human_seg（真人）        │
│        isnet-general-use（通用）                            │
└─────────────────────────────────────────────────────────────┘
```

## 快速开始

环境要求：Python 3.10+（含 3.14），首次运行需联网下载模型（约 176MB）。

```bash
./run.sh
# 打开 http://127.0.0.1:8000
```

`run.sh` 会自动：创建虚拟环境 `.venv` → 安装依赖 → 预下载抠图模型 → 启动服务。

手动方式：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/download_model.py   # 预下载模型（可选）
.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

> 模型放在 `~/.u2net/`，若 GitHub 下载缓慢，可自行多线程下载
> `https://github.com/danielgatis/rembg/releases/download/v0.0.0/isnet-anime.onnx`
> （md5：`6f184e756bb3bd901c8849220a83e38e`）后放入该目录。

## 使用指南

1. **上传素材**：左栏先传「① 现实场景图」，再传「② 角色图」。角色会自动上传服务端抠图（首次需等模型加载，顶栏状态灯会显示进度）；「自动清除残留背景」默认开启，缝隙与碎片会被一并处理。
2. **摆放角色**：在画布上**拖动**移动角色，**滚轮**缩放，**方向键**微调（Shift 大步）；右栏「角色调整」可精确设置大小（%）、旋转角度、水平翻转、不透明度。
3. **光影融合**：点「按场景自动估计光源」得到初始方位，再微调「光源方位」；「定向明暗」让角色朝光面提亮、背光面压暗，「轮廓光」勾出受光边缘，「投影强度/长度」沿光源反方向铺地面投影。
4. **色调融合**：
   - 先打开「自动色调匹配」（默认强度 70%），角色颜色会向场景统计特征迁移；
   - 再用「色彩调整」细调：范围切到**角色**修正人物曝光/色温，切到**场景**统一画面氛围，切到**两者**整体调整。
5. **修饰细节**：
   - 「边缘羽化」柔化抠图硬边（发丝建议 1–3）；
   - 抠图有残留时：**魔棒**点一下残留区域自动清除（容差控制范围，适合双腿间缝隙这类成片残留）；零星杂边用**擦除**笔刷抹掉，误删用**还原**笔刷找回；再点一次工具按钮回到拖动模式。
6. **套用风格**：「风格预设」一键切换整体氛围（已联动光影参数），可在预设基础上继续细调。
7. **导出**：点「保存 PNG / JPG」，按场景原始分辨率输出。

## 参数说明

### 色彩调整（范围：角色 / 场景 / 两者）

| 滑杆 | 范围 | 实现 |
|---|---|---|
| 曝光 | ±100 | `brightness(1+x/100)` |
| 对比度 | ±100 | `contrast(1+x/100)` |
| 饱和度 | ±100 | `saturate(1+x/100)` |
| 色温 | -100 冷 ↔ +100 暖 | soft-light 暖橙/冷蓝叠加（角色层自动保 alpha） |
| 色调 | ±100 | `hue-rotate(±180°)` |

### 角色调整

| 滑杆 | 范围 | 说明 |
|---|---|---|
| 大小 | 5%–800% | 相对基准（角色高 ≈ 场景高 55%） |
| 旋转 | ±180° | 绕角色中心 |
| 不透明度 | 20%–100% | 可做幽灵/半透明效果 |
| 边缘羽化 | 0–12px | alpha 通道盒模糊 ×2 |
| 笔刷大小 | 10–150 | 擦除/还原笔刷直径（画布像素） |
| 魔棒容差 | 10–120 | 魔棒漫水的颜色相似阈值（RGB 欧氏距离） |

### 光影融合

| 控件 | 范围 | 说明 |
|---|---|---|
| 光源方位 | 0–359° | 0=正上顺时针；投影方向/长度自动跟随 |
| 定向明暗 | 0–100% | 受光面提亮、背光面压暗（overlay 混合，颜色取自场景亮/暗部均值） |
| 轮廓光 | 0–100% | 剪影偏移减影得到受光边缘月牙，叠加环境亮色 |
| 投影强度 | 0–100% | 地面投影不透明度 |
| 投影长度 | 0–100% | 剪影压扁/剪切程度，越长越贴地 |

### 手动修图

| 工具 | 说明 |
|---|---|
| 擦除 | 按住拖动，把笔刷圈内的角色 alpha 抹掉（笔刷随角色旋转/翻转/缩放自动映射） |
| 还原 | 擦多了用它找回来 |
| 魔棒 | 单击残留区域，从点击处漫水清除颜色相近的连通区域（容差控制范围）；适合双腿间、手臂与腰间等成片残留 |

### 自动色调匹配

Reinhard 颜色迁移：对角色不透明像素与场景全图分别统计 RGB 均值/标准差，
`x' = (x-μc)·(σs/σc)+μs`，再按强度线性混合。预计算为 3×256 查找表，实时渲染。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 服务与各模型的加载状态（loaded / loading / error） |
| POST | `/api/segment` | multipart 字段 `image`（图片文件）、`model`（默认 `isnet-anime`）、`cleanup`（默认 `true`，残留清理）；返回裁剪过透明边的带 alpha PNG |

错误码：`400` 模型名不合法 / 空文件；`413` 超过 20MB；`422` 图片无法解析；`503` 推理失败（含模型未就绪，可重试）。

## 常见问题

- **顶栏显示「后端未启动」**：确认 `run.sh` / uvicorn 已在运行，端口 8000。
- **抠图很慢**：首次使用需下载模型（约 176MB）或冷加载；之后单张 CPU 推理约 2–5 秒。
- **角色没抠干净 / 多抠了**：先确认「自动清除残留背景」已开启（重新上传生效）；成片残留用**魔棒**点掉，杂边用**擦除**笔刷；真人照片把「抠图模型」换成 `u2net_human_seg`。
- **白裙/白衣被残留清理误删**：角色服装与背景颜色几乎相同且直接接触画面边缘时可能发生，取消勾选「自动清除残留背景」重新上传即可。
- **投影方向不对**：先点「按场景自动估计光源」，再手动微调「光源方位」滑杆。
- **画布操作卡顿**：场景图建议不超过 2048px（前端会自动缩到 2048）。
- **导出的 JPG 有白边**：JPG 不支持透明，透明区域填充白色；需要透明背景请用 PNG。
- **浏览器要求**：Chrome / Edge / Firefox 现代版本（用到 `ctx.filter` 与 ES Module）。

## 后续路线（Phase 3 · 生成式融合）

当前已含确定性光影管线（光源估计 / 定向明暗 / 轮廓光 / 地面投影）。规划中的增强：

1. **生成式光影融合**：对角色边缘/暗部区域用 Flux Kontext / Qwen-Image-Edit 低强度 inpaint，补环境光遮蔽与真实反光（需要 GPU，单张 3–8 秒）；
2. **交互式抠图精修**：接入 SAM2 点选修正（CPU 上单次点击约数秒）；
3. **多角色图层**：支持多个角色独立变换与排序。
