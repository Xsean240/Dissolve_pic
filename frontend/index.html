操作指南

  1. 左侧上传现实场景图（背景），再上传角色图（动漫人物等）。角色会上传到服务端自动抠图，首次抠图需等模型下载/加载。
  2. 角色已在画布中：拖动移动，滚轮缩放，右侧面板可旋转、翻转、调不透明度。
  3. 「自动色调匹配」让角色颜色贴近场景光照；再用「色彩调整」对角色 / 场景 / 两者分别细调曝光、对比度、饱和度、色温、色调。
  4. 「贴地投影」给角色加地面阴影，「边缘羽化」柔化抠图边缘；边缘瑕疵用橡皮擦（擦除 / 还原）修补。
  5. 「风格预设」一键套用常用风格；满意后点「保存 PNG / JPG」导出。
